# React useState Counter

A simple React counter application built while learning the `useState` hook.

## Features

* Increase the counter
* Decrease the counter
* Counter value updates dynamically
* Uses React `useState` hook
* Styled with Tailwind CSS

## Technologies Used

* React
* JavaScript
* Tailwind CSS
* Vite

## What I Learned

* How `useState` works in React
* How to update state using a setter function
* How button click events update the UI
* Basic Tailwind CSS styling
